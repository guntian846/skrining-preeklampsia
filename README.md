# 🩺 Sistem Skrining Preeklampsia

Aplikasi web sederhana untuk membantu deteksi dini dan penilaian risiko **preeklampsia** pada ibu hamil.

## ✨ Fitur Utama
- **Input Data Pasien**: Mengisi data riwayat kesehatan dan faktor risiko ibu hamil.
- **Hasil Skrining Otomatis**: Menentukan tingkat risiko preeklampsia secara cepat.
- **Saran Tindak Lanjut**: Memberikan informasi rekomendasi awal berdasarkan hasil skrining.

## 🛠️ Teknologi
- HTML, CSS, JavaScript
- Hosting: Netlify

## ⚠️ Catatan
Aplikasi ini hanya untuk skrining awal dan edukasi, **bukan pengganti** pemeriksaan langsung oleh dokter atau bidan.
